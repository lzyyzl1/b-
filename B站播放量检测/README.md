# B站话题浏览量查询

查询 **哔哩哔哩话题（#xxx#）的浏览量 / 讨论数 / 动态数**，支持 **关键词搜索** 与 **话题 ID 精确查询**，无需登录 Cookie。
提供两种使用方式：**Web 界面**（推荐）与 **命令行**。

## 安装

```bash
pip install -r requirements.txt     # requests + flask
```

## 方式一：Web 界面（推荐）

```bash
python web_app.py
```

然后浏览器打开 **http://127.0.0.1:5173**

界面功能：

- 顶部两个标签页：**关键词搜索** / **话题 ID 查询**
- 搜索：输入关键词 → 选条数（10/20/30/50）→ 选排序（默认 / 浏览量 / 讨论数）→ 回车或点「查询」
  - 结果以卡片展示，卡片带 `No.1` 排名角标，大字显示浏览量（如 `3.02亿`，下方灰字为原始值 `302,144,665`）
  - 每张卡片含讨论数、动态数、话题简介，可直接「打开话题页」
  - 右上角「导出 CSV」按钮导出当前结果（UTF-8 BOM，Excel 不乱码）
- **聚合统计面板**：结果上方自动展示话题数、浏览量合计/均值/中位数、最高浏览话题、讨论数合计、TOP5 占比，以及浏览量分布条形图（< 1万 / 1万-10万 / 10万-100万 / 100万-1000万 / 1000万-1亿 / ≥ 1亿）
- ID 查询：输入一个或多个 ID（逗号分隔）→ 回车或点「查询」
  - 详情页卡展示浏览量、讨论数、动态数、收藏、点赞、分享、创建者与创建时间
  - 无效 ID 会在顶部单独提示，不影响其他 ID

## 方式二：命令行

### 按关键词搜索话题

```bash
python bili_topic.py search 原神
python bili_topic.py search 原神 -n 30 --sort view      # 取 30 条并按浏览量排序
python bili_topic.py search 原神 --csv result.csv       # 导出 CSV
python bili_topic.py search 原神 --json                 # 附带输出接口原始 JSON
```

### 命令行参数

| 参数 | 说明 |
| --- | --- |
| `-n, --limit` | 搜索返回条数，默认 20（`stats` 默认 30） |
| `--sort` | 排序：`view`(浏览量) / `discuss`(讨论数) / `default`(接口默认) |
| `--json` | 额外打印接口返回的原始 JSON |
| `--csv PATH` | 将结果导出为 CSV |

## HTTP 接口

Web 界面使用的后端接口，也可单独调用：

| 方法 | 路径 | 参数 |
| --- | --- | --- |
| GET | `/api/search` | `keyword`, `limit`(≤50), `sort` |
| GET | `/api/detail` | `ids`（逗号分隔，最多 20 个） |

## 文件结构

```
bili_topic.py        数据层 + 命令行（BiliTopicClient 负责接口请求）
web_app.py           Flask 后端，提供页面与 HTTP 接口
templates/index.html Web 界面（原生 HTML/CSS/JS，无前端依赖）
requirements.txt     requests + flask
```

## 数据来源

| 用途 | 接口 |
| --- | --- |
| 关键词搜索话题 | `https://api.bilibili.com/x/topic/pub/search` |
| 话题 ID 详情 | `https://api.bilibili.com/x/topic/web/details/top` |

均为 B 站 Web 端公开接口。程序会先访问 `bilibili.com` 首页获取 `buvid3` 等匿名 Cookie，以规避风控拦截（返回 `-352`/`-412` 时会自动重试）。

## 注意事项

- 请合理控制请求频率，程序内置了请求间隔与重试，批量采集时不要并发过高。
- 结果中的数字为接口返回的实时值，仅供个人数据统计与分析使用。
